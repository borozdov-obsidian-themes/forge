# Borozdov Forge

A theme from the Borozdov collection. Two faces — dark **Anvil**, a warm obsidian workshop,
and light **Workbench**, the same workshop with the shutters open. Parchment text on
near-black, a teal wash on the side panels, light headlines and one coral glow for the
caret.

![Borozdov Forge in dark mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/forge/main/screenshots/dark.png)

![Borozdov Forge in light mode](https://raw.githubusercontent.com/borozdov-obsidian-themes/forge/main/screenshots/light.png)

## Principles

- **Warm obsidian, never black.** The canvas is a warm near-black, cards are lifted by
  lightness alone, and code sits in a deeper, recessed card. Nothing casts a shadow.
- **A teal wash for the workshop walls.** The side panels, tab bars and status bar take a
  forest-teal tint — an atmosphere, not a surface. Tags are moss badges.
- **Parchment for actions, coral for the caret.** The main button is the only pill on the
  page, parchment with obsidian text; a checked task and a toggle are parchment too.
  Links are parchment with an underline. The one saturated colour, coral, is kept for the
  caret, the highlighter and a link under the pointer.
- **Light, compressed headlines.** The title and the two largest headings at weight 300,
  tracked in; the platform's own sans at 400 for the text; micro-copy in small tracked
  capitals.

## Features

- Dark and light modes, following Settings → Appearance → Base color scheme
- Callouts as raised cards with the title in the type's colour
- Square ghost buttons with a parchment rim beside one parchment pill
- Tables with hairline rules and tracked column labels
- Quiet editing: no focus ring around the note, its title or form fields while you type;
  property names read as labels, not boxed fields
- Text colours meet WCAG contrast on both faces
- The phone layout keeps the same colours and shapes
- No embedded fonts, so the theme stays around 12 KB
- No `!important`: every rule can be overridden with a CSS snippet

## Installation

**From the community directory:** Settings → Appearance → Themes → Manage, search for
**Borozdov Forge**, then **Install and use**.

**By hand:** download `manifest.json` and `theme.css` from the
[latest release](https://github.com/borozdov-obsidian-themes/forge/releases/latest) into
`<vault>/.obsidian/themes/Borozdov Forge/`, then choose Borozdov Forge under
Settings → Appearance → Themes.
